# Aryan Pandey — Portfolio

Personal portfolio website showcasing engineering projects, research, and systems built from 0 to 1.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Framer Motion
- **3D / Visuals:** Three.js
- **Icons:** Lucide React

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
